## 배운 것 / gotchas (다음에 또 만날 것)
1. **`NEXT_PUBLIC_*` env는 빌드 시 클라 번들에 인라인** → `.env.local` 고쳐도 **dev 서버 재시작**해야 브라우저 클라가 새 값 받음(핫리로드 X). 증상: 서버액션은 되는데 클라 읽기 쿼리만 "URL and Key required" 500.
2. **포트**: `:3000`=다른 프로젝트(aj-platform Nuxt), MMA next dev는 **:3002**.
3. **PostgREST 임베드 to-one vs to-many**: NOT NULL FK→단일 객체, nullable/역방향→배열. `sessions(*, taggables(tags(name)), session_techniques(..., techniques(...)), media_links(media_assets(...)))` 다층 중첩 임베드 타입 정상 추론됨.
4. **서명URL 재생**: 비공개 버킷이라 `createSignedUrl`로만. storage RLS `training_media_read_own`(소유자 SELECT) + 경로 `<uid>/videos/...` 일치 → **브라우저 인증 클라가 직접 발급 가능**.
5. **attach 트랜잭션 경계**: tags/media는 RPC 트랜잭션 밖에서 생성 후 id를 RPC에 넘김 → logSession 실패 시 고아 자산. 재사용 자원이라 무해(의도적 트레이드오프).
6. **편집 재동기화 race**: 기술 편집 저장이 "삭제 후 재삽입"이라, prefill 전 저장하면 빈 목록으로 지워짐 → `canSave`에 prefill 완료 게이트 추가로 차단.
7. **zsh**: `git commit -m`에 백틱 금지(명령 치환). 본문은 따옴표만.
