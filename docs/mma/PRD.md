> 제품명: **미정** (가칭 **RollLog**) · 문서 버전 **v0.2 (Draft · 리뷰 1회 반영)** · 작성일 **2026-05-30**

## 0. 한 줄 요약 (Elevator Pitch)

> **"오늘 매트에서 배운 걸, 날짜·종목·벨트·영상으로 남기고 언제든 복습한다."**

주짓수(기/노기)·레슬링·타격(무에타이/킥복싱/복싱)·MMA를 함께 수련하는 사람이, **노션 캘린더처럼 생긴 화면**에서 날짜별 훈련을 기록하고, **내가 찍은 영상**과 **참고 유튜브 영상**을 붙이고, **주의사항 메모**를 남기고, **태그·검색**으로 다시 꺼내 보는 **개인 훈련 일지**.

---

## 1. 배경 & 문제 정의

격투기 수련자는 매 수업마다 다량의 디테일(그립, 각도, 체중 분배, 콤비네이션)을 배우지만 대부분 다음 날이면 잊는다. 기존 도구의 한계:

- **메모 앱(노션/노트)**: 영상 첨부·종목/벨트 분류·태그 검색이 번거롭고 격투기 도메인에 안 맞음.
- **유튜브 즐겨찾기**: 내 훈련 기록과 분리됨. "내가 언제 이걸 드릴했는지"와 연결 안 됨.
- **카메라 롤**: 영상이 쌓이지만 맥락(무슨 기술, 어떤 포지션, 무슨 주의점)이 사라짐.

**핵심 통찰**: 수련자에게 필요한 건 "기록"이 아니라 **"복습 가능한 기록"** 이다. = 날짜 × 종목 × 기술분류 × 벨트 × 영상 × 태그가 한 곳에 묶여야 한다.

## 2. 목표 / 비목표

### 2.1 목표 (Goals)
- G1. **마찰 없는 기록**: 수업 직후 1~2분 안에 "오늘 뭐 했는지"를 남길 수 있다.
- G2. **복습 중심**: 과거 기록을 날짜·태그·검색으로 빠르게 다시 찾는다.
- G3. **격투기 도메인 1급 시민화**: 종목·벨트·포지션·기술분류가 데이터 모델과 UI의 핵심이다.
- G4. **영상 친화**: 내 영상(짧은 클립)과 참고 유튜브를 같은 기록에 자연스럽게 붙인다.
- G5. **웹·모바일 동시 제공**: 매트에서(모바일) 찍고, 집에서(웹) 정리·복습한다.

### 2.2 비목표 (Non-Goals) — MVP에서 명시적으로 안 함
- N1. **소셜/피드/팔로우** — 개인 일지에 집중 (단, 데이터모델은 향후 공유 대비, §12).
- N2. **권위 있는 "벨트별 기술 표준 DB"** 제공 — 벨트 적합도는 **사용자가 직접 태깅**하는 주관 정보 (§4.3).
- N3. **자동 영상 분석/AI 자세 교정** — 향후 검토.
- N4. **대회 매치 트래킹/스코어링** — P2 이후.
- N5. **단위 변환·체중 관리·식단** 등 피트니스 트래킹 — 범위 외.
- N6. **완전한 오프라인 우선(offline-first)** — 범위 외(P2+). 단, 신호 약한 체육관 대비 **촬영/기록 후 업로드 큐 + 로컬 임시저장**은 **P1**로 포함(§9).

## 3. 타겟 사용자 & 페르소나

| | |
|---|---|
| **1차 사용자** | 본인 — 주짓수/레슬링/타격을 병행 수련하는 생활체육인. 주 3~6회 훈련, 가끔 스파링 영상 촬영. |
| **숙련도** | 종목별로 다름 (예: 주짓수 블루벨트, 레슬링 입문, 타격 중급). 종목별 랭크를 따로 관리해야 함. |
| **기기** | 매트에서는 **휴대폰**(촬영·즉석 기록), 복습·정리는 **웹/태블릿**. |
| **2차 사용자 (향후)** | 코치/팀 동료 — 특정 기록을 공유받아 피드백. (P2, §12) |

**페르소나 핵심 니즈**: "어제 교수님이 알려준 그 디테일이 뭐였지?" → 3초 안에 찾기.

## 4. 도메인 용어집 & 분류체계 (SSoT)

> ⚠️ 이 절의 enum 값·명칭은 DB enum, TS 타입, UI 라벨의 기준이다. 변경 시 PRD를 먼저 고친다.

### 4.1 종목 (Discipline) — `discipline`
하나의 세션/기술이 속하는 최상위 분류.

| 코드 | 한글 라벨 | 설명 |
|------|----------|------|
| `bjj_gi` | 주짓수 (기) | 도복 주짓수 |
| `bjj_nogi` | 노기 주짓수 | 래시가드/노기 |
| `wrestling` | 레슬링 | 테이크다운·그라운드 컨트롤 |
| `striking` | 타격 | 무에타이·킥복싱·복싱 **통합** |
| `mma` | MMA | 통합 룰 / 케이지 워크 |

- 타격 세부 스타일은 별도 종목이 아니라, 타격 기술/세션에 부여하는 **선택형 필드 `striking_style`** 로 구조화한다(필터·통계 가능 — 사용자 결정). 값: `muay_thai`(무에타이), `kickboxing`(킥복싱), `boxing`(복싱), `other`(기타). 비타격은 null. (DB 배치는 Develop — 기본 technique, 세션에도 선택 부여 가능.)
- 한 세션은 **여러 종목**을 포함할 수 있다 (예: 주짓수 + 노기). → 세션:종목 = N:M.

### 4.2 기술 분류 (Technique Category) — `technique_category`
종목군에 따라 의미가 다르며, UI는 종목에 맞는 분류만 노출한다.

- **그래플링군**(bjj_gi/bjj_nogi/wrestling): `guard`(가드), `pass`(패스), `sweep`(스윕), `submission`(서브미션), `takedown`(테이크다운), `escape`(이스케이프), `transition`(트랜지션), `control`(컨트롤/포지셔닝), `defense`(디펜스)
- **타격군**(striking): `punch`(펀치), `kick`(킥), `knee`(니), `elbow`(엘보), `clinch`(클린치), `combination`(콤비네이션), `defense`(디펜스/가드), `footwork`(풋워크)
- **공통**: `entry`(셋업/진입 — 서브미션·클린치 등으로 들어가는 셋업)
- `mma`: 위 전부 + `cage_work`(케이지 워크), `ground_and_pound`
- ℹ️ enum은 운영하며 **확장 가능**(과도한 세분화는 지양 — 세부는 기술 이름/태그로).

### 4.3 벨트 (Belt) — `belt` *(주짓수 전용)*
- 값: `white`, `blue`, `purple`, `brown`, `black` (+ `stripes` 0~4)
- **용도 1 (사용자 랭크)**: 종목별 내 현재 벨트 (기/노기는 보통 동일 벨트).
- **용도 2 (기술 적합도)**: 기술 카탈로그 항목에 "이 기술은 대략 어느 벨트 단계의 것"인지 **사용자가 직접 태깅**. 권위 있는 표준이 아니라 본인 기준의 가이드. UI에 **벨트 배지**로 예쁘게 표시 (사용자 요청).
- 레슬링/타격은 벨트가 없음 → 해당 종목 기술엔 벨트 배지 대신 **종목 배지만** 표시. (필요 시 `level`: 입문/중급/고급 옵션 — P1)

### 4.4 포지션 (Position) — `position` *(주로 그래플링)*
`standing`, `clinch`, `closed_guard`, `open_guard`, `half_guard`, `mount`, `side_control`, `back_control`, `turtle`, `north_south`, `knee_on_belly`, `other`
- ℹ️ 세부 가드(델라히바·스파이더 등)는 `open_guard` + 기술 이름/태그로 표현. enum은 확장 가능.

### 4.5 수업 유형 (Class Type) — `class_type`
`technique`(기술수업), `drilling`(드릴), `sparring`(스파링/롤링), `open_mat`(오픈매트), `private`(개인레슨), `seminar`(세미나), `competition`(대회), `strength`(체력/컨디셔닝)

### 4.6 핵심 객체 정의
- **세션 (Session)**: 특정 **날짜**의 한 번의 훈련. 캘린더의 기본 단위. 종목·체육관·수업유형·시간·강도·파트너·요약메모·평점을 가짐.
- **기술 (Technique)**: 재사용 가능한 **기술 카탈로그 항목**. 종목·분류·포지션·(벨트)·설명·디테일/주의점·미디어·태그를 가짐. 여러 세션에서 참조됨 → **복습의 단위**.
- **세션-기술 로그 (Session Technique)**: "이 세션에서 이 기술을 다뤘다"는 연결 + 그날만의 메모.
- **미디어 (Media Asset)**: 내 업로드 영상 / 유튜브 / 외부링크. 세션 또는 기술에 첨부.
- **태그 (Tag)** + **태그 연결 (Taggable)**: 세션·기술에 자유 태그. 검색/필터의 축.

## 5. 핵심 사용자 시나리오 (User Journeys)

**J1. 수업 직후 기록 (모바일, ~90초)**
1. 앱 열기 → 오늘 날짜에 `+` → "세션 추가".
2. 종목(노기 주짓수), 체육관, 수업유형(드릴) 선택.
3. 방금 찍은 클립을 **바로 업로드**(짧은 클립) 또는 유튜브 링크 붙임.
4. "다룬 기술" = `백 컨트롤 → 보우앤애로우 초크` 선택/신규 생성, 주의점 메모: "상대 팔 묶고 들어가기".
5. 태그 `#보우앤애로우 #백테이크` → 저장.

**J2. 복습 (웹, 주말)**
1. 캘린더 월간 뷰 → 빨간 점 많은 주 클릭 → 그날 디테일.
2. 기술 카드 열어 내 영상 + 참고 유튜브 나란히 보기.
3. 주의점 메모 재확인.

**J3. 태그/검색으로 꺼내기**
1. 상단 검색바에 "보우앤애로우" → 관련 기술·세션·영상 모아보기.
2. 또는 태그 `#스윕`만 필터 → 지금까지 저장한 스윕 전부.

**J4. 종목/벨트 한눈에**
1. 기술 목록에서 각 카드의 **종목 배지(노기)** + **벨트 배지(블루)** 로 적합도 즉시 인지.

## 6. 기능 요구사항 (Features)

> 우선순위: **P0 = MVP 필수**, **P1 = MVP 직후**, **P2 = 향후**. 각 기능은 사용자 스토리 + 수용 기준(AC)으로 정의.

### F1. 인증 · 프로필 · 종목별 랭크  `P0`
- US: 사용자로서 로그인하여 내 기록을 안전하게 보관하고, 종목별 내 벨트/레벨을 설정하고 싶다.
- AC1. 이메일/소셜 로그인(Supabase Auth)으로 가입·로그인된다.
- AC2. 모든 데이터는 본인만 접근 (RLS, §Develop). 타인 데이터 접근 불가.
- AC3. 프로필에 표시명·타임존(기본 Asia/Seoul) 설정.
- AC4. **종목별 랭크**를 따로 설정: 주짓수=블루(스트라이프 2), 레슬링=입문, 타격=중급 등.
- AC5. (향후 공유 대비) 모든 사용자 소유 레코드는 `visibility` 시드를 갖되 MVP에선 항상 `private`.

### F2. 캘린더 (Notion형 메인 화면)  `P0`
- US: 노션 캘린더처럼 생긴 화면에서 날짜별로 무엇을 했는지 한눈에 보고, 날짜를 눌러 상세를 보고 싶다.
- AC1. **월간 그리드**가 기본. 각 날짜 셀에 그날 훈련한 **종목 색 점/칩**과 세션 수 표시.
- AC2. 오늘 날짜 강조. 빈 날과 기록 있는 날이 시각적으로 구분.
- AC3. 날짜 셀 클릭 → **하루 상세**(Day Detail): 그날의 세션 목록 → 각 세션의 기술·미디어·메모.
- AC4. 날짜 셀/상세에서 `+`로 그 날짜에 **세션 바로 추가**.
- AC5. 월 이동(이전/다음), "오늘로" 점프.
- AC6. (P1) 주간 뷰 / 아젠다(리스트) 뷰 토글.
- 참고: 웹은 `react-calendar`(이미 설치됨) 기반 커스텀. 모바일은 동일 화면을 WebView로 제공.

### F3. 훈련 세션 기록 (CRUD)  `P0`
- US: 한 번의 훈련을 빠르게 기록/수정/삭제하고 싶다.
- AC1. 필드: 날짜(필수), 종목(1개 이상, 필수), 체육관/장소, 수업유형, 시간(분), 강도(1~5), 라운드 수, 파트너(자유 텍스트), 요약 메모, 평점(1~5, 선택).
- AC2. 세션에 **다룬 기술**을 N개 연결(기존 선택 또는 신규 생성) + 기술별 그날 메모.
- AC3. 세션에 **미디어**(내 영상/유튜브/링크) N개 첨부 (F5).
- AC4. 세션에 **태그** N개 (F7).
- AC5. 생성/수정/삭제가 즉시 캘린더에 반영.
- AC6. 입력 최소화: 종목+날짜만으로도 저장 가능(나머지 선택).

### F4. 기술 라이브러리 (Technique Catalog)  `P0`
- US: 재사용 가능한 "기술" 항목을 만들어 종목·분류·포지션·벨트로 정리하고, 복습하고 싶다.
- AC1. 기술 필드: 이름(필수), 종목(필수), 분류(§4.2), 포지션(§4.4, 선택), **벨트 적합도**(주짓수만, 선택), **타격 스타일**(`striking_style`, 타격만, 선택), 설명(마크다운), **주의점/디테일**(F6), 미디어(F5), 태그(F7).
- AC2. 기술 목록: 카드 그리드. 각 카드에 **종목 배지** + (주짓수면)**벨트 배지** + 대표 썸네일.
- AC3. 기술 상세: 설명·디테일·내 영상·참고 유튜브·"이 기술을 다룬 세션들"(역참조) 표시.
- AC4. 분류/포지션/벨트/종목으로 필터.
- AC5. 기술은 여러 세션에서 참조 가능(복습 단위).

### F5. 미디어 — 내 영상(하이브리드) + 참고 유튜브  `P0`
- US: 내가 찍은 영상과 참고 유튜브 영상을 기록에 붙이고 싶다.
- AC1. **내 영상 — 하이브리드 저장 정책**:
  - **짧은 클립**(기준: ≤ 약 60초 / ≤ 약 100MB, 정확 한도는 Develop에서 확정)은 **Supabase Storage에 직접 업로드**.
  - 그보다 긴 영상은 **유튜브(비공개/미등록) 또는 외부 링크**로 붙이도록 안내.
  - 업로드 시 진행률·취소·실패 재시도.
  - **플랫폼 단계화(사용자 결정)**: **P0** = 웹 + 모바일 WebView에서 **웹 파일선택/`getUserMedia`** 로 업로드. **P1** = 모바일 **네이티브 촬영/갤러리 브릿지**(WebView↔Expo) + **오프라인 업로드 큐·로컬 임시저장**.
  - 긴 영상은 §F5-AC1대로 유튜브(미등록)/외부 링크(현장 수동 — 저장비용 우선, 알려진 트레이드오프).
- AC2. **유튜브 참고영상**: URL 붙여넣기 또는 **앱 내 유튜브 검색**(`/api/youtube/search` 재사용)으로 추가 → 카드에 임베드 재생.
- AC3. 미디어는 세션 또는 기술에 첨부, 한 미디어가 양쪽에 연결 가능.
- AC4. 내 업로드 영상은 **본인만** 재생 가능(서명 URL, 비공개 버킷).
- AC5. 썸네일: 업로드 영상은 자동/수동 썸네일, 유튜브는 기본 썸네일.

### F6. 메모 · 주의사항  `P0`
- US: 기술·세션마다 "주의해야 할 점"을 따로 강조해 남기고 싶다.
- AC1. 세션 요약 메모(자유 텍스트/마크다운).
- AC2. 기술의 **주의점/디테일** 필드를 별도로 두고 상세에서 시각적으로 강조(예: 빨강 강조 박스).
- AC3. 세션-기술 연결마다 "그날의 메모"를 따로 남길 수 있음.

### F7. 태그 & 태그 검색  `P0`
- US: 저장한 것을 태그로 분류하고, 태그로 모아 보고 싶다.
- AC1. 세션·기술에 자유 태그 부여(자동완성, 신규 생성 허용).
- AC2. **태그별 보기**: 태그 선택 시 그 태그가 달린 세션·기술 모아보기.
- AC3. 다중 태그 AND 필터.
- AC4. (P1) 태그 색상/이름 변경, 사용 빈도순 정렬.

### F8. 검색바 (글로벌 검색)  `P0`
- US: 상단 검색바에서 키워드로 기술·세션·태그를 한 번에 찾고 싶다.
- AC1. 상단 고정 검색바. 키워드로 **기술 이름/설명, 세션 메모/체육관, 태그**를 통합 검색.
- AC2. 부분일치(한글 포함) — `pg_trgm` 기반(기존 패턴 재사용).
- AC3. 결과는 타입별(기술/세션/태그) 그룹핑, 클릭 시 해당 상세로.
- AC4. (P1) 종목·벨트·기간 등 패싯 필터 결합.

### F9. 벨트 · 종목 비주얼 시스템  `P0`
- US: 주짓수면 벨트에 맞는 기술인지, 그리고 기/노기/레슬링/타격 중 무엇인지 예쁘게 표시되면 좋겠다.
- AC1. **벨트 배지** 컴포넌트: 벨트 색(흰/파랑/보라/갈/검) + 스트라이프 표현. 주짓수 기술/랭크에만.
- AC2. **종목 배지/칩**: 5종(기/노기/레슬링/타격/MMA) 각각 고유 색·아이콘.
- AC3. 배지는 캘린더 점, 기술 카드, 세션 헤더, 검색 결과에서 일관되게 재사용.
- AC4. 색약 고려: 색 + 텍스트/아이콘 동시 사용.

### F10. (P1) 통계 대시보드
- 매트 타임 합계, 종목별 세션 분포, 주/월 빈도, 스트릭, 가장 많이 복습한 기술 등.

### F11. (P2) 공유 & 협업
- 특정 세션/기술을 코치·동료에게 링크/초대 공유, 코멘트. §12.

## 8. 데이터 모델 (개념 ERD)

> 개념 수준만. 컬럼·enum·RLS·인덱스의 **확정 스키마는 Develop.md**.

```
auth.users (Supabase)
  └─1:1─ profiles
            └─1:N─ user_ranks (discipline, belt/level)

profiles(user)
  ├─1:N─ sessions ──N:M(session_disciplines)── discipline(enum)
  │         ├─1:N─ session_techniques ──N:1── techniques
  │         └─(메모/평점/체육관/유형/시간)
  ├─1:N─ techniques (discipline, category, position, belt, 설명, 주의점)
  ├─1:N─ media_assets (kind: upload|youtube|external) ──> 세션 또는 기술에 연결
  └─1:N─ tags ──N:M(taggables)── (sessions | techniques)
```

핵심 관계:
- 세션 ↔ 종목: N:M (한 훈련에 복수 종목).
- 세션 ↔ 기술: N:M (`session_techniques`, 그날 메모 보유).
- 미디어 ↔ (세션|기술): 폴리모픽 연결(한 미디어가 양쪽에 붙을 수 있음).
- 태그 ↔ (세션|기술): 폴리모픽 N:M(`taggables`).
- 모든 사용자 데이터: `user_id` 소유 + `visibility`(MVP=private, 공유 대비).

## 12. 향후 확장 — 공유 (데이터모델 사전 대비)

MVP는 1인용이지만, **나중에 코치/동료 공유**를 위해 지금부터 다음을 심어 둔다(과한 구현은 안 함):
- 모든 사용자 소유 테이블에 `visibility`(`private`|`shared`|`public`, 기본 `private`) 컬럼 시드.
- 향후 `shares`(리소스, 대상 사용자, 권한) 테이블 추가 지점만 확보 — MVP 미구현.
- RLS는 MVP에서 `auth.uid() = user_id`로 단순 유지, 공유 도입 시 정책 확장.
