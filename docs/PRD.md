# PRD (Product Requirements Document)

**프로젝트명:** 스마트 냉장고 & 레시피 매니저 (가칭: 지혜로운 식탁)

---

## 1. 프로젝트 개요

**목적:** 보유 중인 식재료를 직관적으로 파악하고, 이를 활용한 레시피 추천부터 부족한 식재료 구매까지 연결하여 '식재료 낭비 방지'와 '메뉴 고민 해결'을 동시에 달성하는 올인원 홈쿠킹 앱.

**타겟 유저:** 집에서 정기적으로 요리하며, 남은 식재료를 효율적으로 소진하고 관리하고 싶은 사람.

**개발 환경:** 하이브리드 앱 (Hybrid App)

- 웹 기술(React, Vue, Next.js 등)을 기반으로 UI 및 비즈니스 로직을 구현하고, 네이티브 웹뷰(WebView)로 패키징하여 Android와 iOS에 동시 서비스.
- 영수증 OCR 촬영, 바코드 스캔 등 기기 하드웨어 제어가 필요한 영역은 하이브리드 브릿지 기술(Capacitor, React Native WebView Interface 등)을 활용하여 웹과 네이티브 간 연동.

---

## 2. 핵심 기능 요구사항 (Core Features)

### 2.1. 인벤토리 관리 (스마트 냉장고)

- **직관적인 UI:** 냉장고에 있는 식재료들을 사용자가 한눈에 알아보기 쉽게 시각적으로 정렬 및 표시 (보관 장소별/카테고리별 분류 기능 포함).
- **보관 기한 트래킹:** 각 식재료별 유통기한 및 소비기한을 표시하여, 기한이 임박한 재료를 우선적으로 소비할 수 있도록 시각적 알림(D-Day) 제공.

### 2.2. 스마트 식재료 입력 고도화

- **영수증 OCR 촬영:** 마트 영수증을 스마트폰 카메라로 촬영하면, 내장된 텍스트 인식(OCR) 기능을 통해 구매한 식재료 품목과 수량을 추출하여 냉장고 인벤토리에 일괄 자동 등록.
- **바코드 스캔:** 가공식품이나 신선식품의 바코드를 스캔하여, 상품명 및 기본 보관 정보를 데이터베이스에서 불러와 빠르고 정확하게 등록.

### 2.3. 맞춤형 레시피 큐레이션 및 미디어 연동

- **보유 재료 기반 추천:** 현재 냉장고에 등록된 식재료 데이터를 교차 분석하여, 당장 조리 가능한 최적의 요리 레시피 리스트 추천.
- **미디어 연동:** 텍스트 형태의 레시피 가이드뿐만 아니라, YouTube API 등을 활용하여 해당 요리의 조리 영상 썸네일과 링크를 제공하여 시각적인 이해도 향상.

### 2.4. 요리 기록 및 식재료 기반 확장 탐색

- **히스토리 아카이빙:** 과거에 냉장고 재료를 활용하여 만들었던 요리 기록(레시피, 소진한 재료 등)을 개인 히스토리에 데이터로 저장.
- **재료 기반 듀얼 추천:** 인벤토리에서 특정 식재료를 클릭했을 때 다음 두 가지 정보를 병렬로 제공하여 메뉴 선택권 확장.
  - 이전에 해당 재료를 주재료로 사용했던 **'과거 요리 레시피'**
  - 해당 재료를 새롭게 활용할 수 있는 **'새로운 요리 레시피'**

### 2.5. 장보기 브릿지 (부족 식재료 구매 연동)

- **부족 재료 계산기:** 특정 추천 레시피를 선택 시, 해당 요리에 필요한 전체 식재료 목록과 현재 사용자의 냉장고 보유 식재료를 대조 계산. 이를 통해 **'냉장고에 없는 부족한 식재료'**만 자동 추출하여 안내.
- **커머스 다이렉트 이동:** 부족한 식재료를 바로 보충할 수 있도록, 해당 재료 클릭 시 파트너사(쿠팡, 배달의민족 B마트, 마켓컬리, 외부 식재료 도매상 등)의 상품 검색 결과 페이지나 구매 페이지로 즉시 연결 (Outlink 및 Deep Link 활용).
